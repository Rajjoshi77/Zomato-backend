# Zomato Backend Clone

A production-style backend built with Node.js, Express, MongoDB, and JWT.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Postman

## Features

- User Registration
- User Login
- Password Hashing
- JWT Authentication
- MVC Architecture
- MongoDB Integration

## Run Locally

```bash
npm install
npm run dev
